# IBM webMethods Zero to Hero 🚀

Welcome to **IBM webMethods Zero to Hero** — a practical, hands-on learning journey to help you learn and build integrations using **IBM webMethods**.

This repository is focused on learning by building, with step-by-step tutorials, hands-on labs, examples, and real-world integration scenarios.

---

## What is IBM webMethods?

**IBM webMethods** is IBM's integration technology for connecting applications, APIs, data, partners, and business processes across enterprise environments.

webMethods supports different deployment models, including:

* **On-premises**
* **Containerized deployments** using **IBM CloudPak for Integration (CP4i)**
* **Cloud / SaaS** using **IBM webMethods Hybrid Integration (IWHI)**

The tutorials in this repository will explore webMethods across these deployment options, wherever applicable.
